# Muhammad Husnain · Portfolio

Personal site for selected work, practice, experience, and contact.

## Setup

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` – local development
- `npm run build` – production build
- `npm run preview` – preview the production build
- `npm run lint` – lint with oxlint

## Content

Edit copy, projects, and links in `src/data/content.ts`.

Intro plays on every visit/refresh. Skip it with `?intro=0`.
